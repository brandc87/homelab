# UniFi

This OpenTofu root adopts the existing UDM SE configuration. It has separate
state from Proxmox so gateway changes never share a plan or blast radius with
virtual-machine changes.

## Safety rules

- Export a current UniFi console backup before every adoption phase.
- Run initial imports from a wired trusted/management connection.
- Never apply a plan that replaces or destroys an existing network.
- Import and reach a no-change plan before making intentional changes.
- Keep autogenerated and unsupported UniFi settings outside OpenTofu.

## Authentication

Create a dedicated **local** UniFi administrator named `unifi-terraform` and
store its username and password in the matching 1Password item in the Homelab
vault. Cloud/SSO credentials and MFA prompts are unsuitable for unattended
provider authentication.

The checked-in `.env.op.tpl` contains only 1Password references. Run OpenTofu
through one authenticated 1Password session:

```bash
cd terraform/unifi
op run --env-file=.env.op.tpl -- tofu init
op run --env-file=.env.op.tpl -- tofu plan
```

No resources are defined initially, so the first plan must report no changes.

See `IMPORTS.md` for the staged adoption process.
