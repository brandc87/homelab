# UniFi adoption plan

Do not create replacement networks. Each existing controller object is first
described in configuration and then imported using its controller ID.

## Phase 0: prerequisites

1. Download and retain a current UDM SE console backup.
2. Use a wired trusted or management connection.
3. Create the dedicated local `unifi-terraform` administrator.
4. Store its credentials in 1Password.
5. Record the UniFi OS and Network application versions.

## Phase 1: existing networks

Adopt one network at a time in this order:

1. Management — VLAN 1 — `10.15.1.0/24`
2. Trusted — VLAN 10 — `10.15.10.0/24`
3. Secure — VLAN 20 — `10.15.20.0/24`
4. Production — VLAN 30 — `10.15.30.0/24`
5. DMZ — VLAN 40 — `10.15.40.0/24`

For every network:

1. Capture all current DHCP, DNS, domain, IPv6, isolation, multicast and lease
   settings from the controller.
2. Add the matching `unifi_network` resource with `prevent_destroy`.
3. Import its controller ID.
4. Run `tofu plan` and reconcile configuration until it reports no changes.
5. Do not proceed while replacement, deletion, or unexplained changes remain.

Only after VLAN 20 has a no-change plan should its display name be changed from
`Secure` to `Work`.

## Phase 2: existing edge configuration

Import and reach a no-change plan for:

- Trusted Wi-Fi network.
- Plex TCP 32400 port forward.
- Palworld UDP 8211 port forward.
- HTTP/HTTPS TCP 80 and 443 port forward.

Record and verify the exact internal destination IP of every port forward.

## Phase 3: firewall policy

Import existing custom firewall zones and policies without changing them.
Autogenerated policies remain controller-owned. Add explicit policy attributes
where the provider normalizes empty values before considering an apply.

## Phase 4: new networks

After the imported baseline is stable, add:

| Network | VLAN | Subnet |
| --- | ---: | --- |
| IoT | 50 | `10.15.50.0/24` |
| Children | 60 | `10.15.60.0/24` |
| EVE-MGMT | 70 | `10.15.70.0/24` |
| EVE-LAB | 71 | `10.15.71.0/24` |

Add associated Wi-Fi networks and default-deny policy exceptions in separate,
reviewable plans.
